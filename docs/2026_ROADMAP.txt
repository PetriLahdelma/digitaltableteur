Persona 1 — Lead Architect (Software/Cyber/Scale)
Technical & Security Assessment


Architecture/hosting: Public repo suggests a React + Vite static deployment (GitHub Pages). Great for speed/cost, but lacks SSR/ISR for SEO and link unfurling. Consider Next.js or Astro with SSR/SSG/ISR and <head> control. GitHub


SEO/preview issues: Root returns “Enable JavaScript” when JS is blocked, which also affects crawlers, link previews, and accessibility fallbacks. SSR or a pre-rendered shell fixes this. Digitaltableteur


AppSec baseline:


Enforce security headers (CSP, HSTS, X-Frame-Options, Referrer-Policy).


Use Subresource Integrity for third-party scripts.


Least-privilege on GH Pages and workflow tokens; pin Actions.


Privacy: explicit analytics consent and DPA with your analytics vendor.




Perf/Resilience:


Optimize LCP (critical CSS, image dims, font loading swap, cache headers).


Uptime checks + synthetic journeys (e.g., contact form).


Backups of site and content (repo + assets).




Future-proofing:


Design tokens repo + Storybook for any live component demos you want to expose.


Content in MDX + CMS (e.g., Contentlayer/Sanity) to iterate fast without code deploys.


API façade for AI demos (rate limiting, logging, key vault).




Architect’s Recommendations (high-impact)


Migrate to Next.js (or Astro) with SSR/ISR, preserve Vite-level DX via Turbopack/Vite plugins.


Harden security headers and add CI checks (OWASP ZAP baseline in CI).


Switch to edge image optimization and implement font subsetting.


Add structured data (Organization, Person, Article, Service) for rich results.


Stand up a small “AI demo” microservice with audit logs + abuse protection.
