# Link

**Status:** stable · **Tier:** atom · **Group:** navigation

Inline navigation anchor with built-in URL sanitisation and an external-link
affordance. Link normalises and validates the `href` (only `http` / `https` /
`mailto` / `tel`, with relative paths preserved), then renders a trailing icon
when the destination is off-site. Colour, the focus ring, and the shared wavy
underline are token-driven, so the contract survives theme swaps and
forced-colors mode. Sizes are `sm` / `md` / `lg`.

## In use

Used in body copy, navigation lists, footer columns, and the `Breadcrumb`
component. The **Example** story shows the canonical inline anchor; the
**External** story exercises the off-site affordance.

Two compositions worth cribbing:

- **Inline body anchor.** Drop a `<Link href="/about">` inside a `<Text>`
  paragraph; the wavy underline follows the token-driven treatment.
- **External link with hint.** Pass an off-site `href` (anything that doesn't
  resolve to a `digitaltableteur.com` host or a relative path). The component
  appends an external icon and adds `rel="noopener noreferrer"` when
  `target="_blank"` is set.

Anti-pattern to avoid: using Link to render a button-shaped CTA. The idiom for
actions is **Button** (use `Button` with `href` for the button look on a
navigation surface).

## How to use

```tsx
import Link from '@dt/Link';

// Inline anchor
<Link href="/about">About us</Link>

// External link (auto-detects, adds the icon, and rel for target=_blank)
<Link href="https://github.com/digitaltableteur" target="_blank">GitHub</Link>

// Mailto / tel
<Link href="mailto:hello@digitaltableteur.com">hello@…</Link>

// Sized inline anchor in editorial copy
<Link href="/work" size="lg">See the work</Link>
```

Required consumer wiring: none. The component sanitises `href` unconditionally —
invalid protocols (`javascript:`, `data:`) are rewritten to `#`, so a stray
pasted URL cannot become an XSS surface.

Theme & forced-colors: link colour reads `--link-color` and survives both
themes; the focus ring uses `--focus-ring-*` and the **ForcedColors** story
verifies the anchor under the system palette.

## When to use

- Inline navigation anchor in body copy.
- A link in a navigation list, breadcrumb, or footer column.
- A mailto / tel affordance.

## When not to use

- A primary action — use **Button**.
- A button styled as a link — use **Button** with `variant="tertiary"`, which
  preserves the right keyboard and ARIA contract.

## Accessibility

- **Native anchor:** the underlying element is a real `<a>`; keyboard and focus
  behaviour is the platform's.
- **External hint:** off-site links append an icon labelled "External link";
  pass `target="_blank"` to open a new tab, and `rel="noopener noreferrer"` is
  added automatically.
- **URL sanitisation:** invalid protocols are rewritten to `#`; the surface API
  cannot inject `javascript:` or `data:` URLs.
- **Focus:** a `focus-visible` ring only (`--focus-ring-*`); mouse clicks do not
  show it.
- **Reduced motion:** only a colour transition runs; there is no movement.
