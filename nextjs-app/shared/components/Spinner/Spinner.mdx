# Spinner

**Status:** alpha · **Tier:** atom · **Group:** feedback

## In use

See the **Example** story for the canonical production composition.

## How to use

```tsx
import { Spinner } from '@dt/Spinner';

<Spinner />
```

## When to use

- When the **Example** story matches your layout or flow.
- When design tokens and theme context from `ThemeProvider` are already mounted.

## When not to use

- When a smaller primitive (link, text, icon) covers the need without extra chrome.
- When the composition is one-off and not worth standardising in the design system.

## Accessibility

- Exercise keyboard, focus, and screen-reader behaviour in **Playground** and **Example**.
- Confirm **ForcedColors** for high-contrast regressions; run `npm run test:stories:hc` before marking `forcedColorsVerified`.
