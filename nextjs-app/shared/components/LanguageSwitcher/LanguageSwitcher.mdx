# LanguageSwitcher

A compact language selector: a current-language trigger that fans out the other
locales as a button group. Lives in the site header.

<Canvas of={LanguageSwitcherStories.Default} />

## In use

Production home is the site header (`SiteHeader`), where space is tight and the
control must show the active language and reveal alternatives on demand.

<Canvas of={LanguageSwitcherStories.Example} />

## How to use

```tsx
import { LanguageSwitcher } from "@dt/LanguageSwitcher";

const LANGUAGES = [
  { code: "en", label: "EN", ariaLabel: "English" },
  { code: "fi", label: "FI", ariaLabel: "Finnish" },
  { code: "sv", label: "SV", ariaLabel: "Swedish" },
];

<LanguageSwitcher
  languages={LANGUAGES}
  currentLang={lang}
  onLanguageChange={setLang}
/>;
```

Keep language state in the parent; the component is presentational.

## When to use

- A header/footer locale switch with 2–4 languages.
- Anywhere a lightweight, space-efficient language control is needed.

## When not to use

- Long locale lists — use a proper `Select`/listbox.
- As primary navigation — it complements the nav, not replaces it.

<Controls />

## Accessibility

- `role="group"` with `aria-label`; trigger exposes `aria-expanded`,
  `aria-controls`, and `aria-current`.
- Options are native buttons with per-language `aria-label`s.
- Escape and outside-click close; reduced motion swaps the fan for a fade.
