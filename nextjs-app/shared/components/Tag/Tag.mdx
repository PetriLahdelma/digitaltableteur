# Tag

**Status:** alpha · **Tier:** atom · **Group:** display

Render a single category, status, or filter label. Visual sibling of `Badge` — `Tag` is the lighter catalog atom used by content surfaces (article meta, filter pills).

## In use

See the **Default** and **Playground** stories. Example and ForcedColors
stories are added at the alpha → beta promotion (see Roadmap Phase 2).

## How to use

```tsx
import { Tag } from '@dt/Tag';

<Tag variant="secondary" size="sm">Design systems</Tag>
```

## When to use

- Article metadata (category, tag list).
- Filter pill rows on a list page.
- Status chip inside a row of a table or list item.

## When not to use

- Numeric counts on icons — that is `Badge`.
- Anywhere the tag needs a strict semantic contract (announcements, polite live region) — `Badge` is gated tighter.

## Accessibility

### Keyboard

- Backspace / Delete on a removable tag triggers the dismiss action when the close affordance is focused.

### ARIA / semantics

- Static tags need no own ARIA; the visible text is the announcement.
- Removable tags expose the dismiss control as a button with an accessible name like 'Remove {label}'.

### Reduced motion

- No own motion.
