# Logo

The Digitaltableteur brand mark. Monochrome (inherits `currentColor`), renders in
a square `size`×`size` box, and supports an opt-in hover pulse.

<Canvas of={LogoStories.Default} />

## In use

In production the mark sits beside the wordmark in the header and footer, and
stands alone in compact spots (loading states, the favicon-as-component). It
inherits the surrounding text color, so it reads correctly in every theme
without per-placement styling.

<Canvas of={LogoStories.Example} />

## How to use

```tsx
import Logo from "@dt/Logo";

<Logo size={28} />
<Logo size={28} animated />        {/* hover pulse, reduced-motion safe */}
<Logo badge />                     {/* lime brand lockup */}
<Logo decorative />                {/* next to a visible wordmark */}
```

To recolor, set `color` on the parent — never hardcode a fill on the mark.

## When to use

- Anywhere the Digitaltableteur brand needs to appear as a mark: header/footer,
  loading and empty states, share images, compact navigation.
- As the home link target — wrap `Logo` in a link or `Button` that owns focus.

## When not to use

- As a generic icon — use `Icon` for UI glyphs.
- Inside a fixed-color box that fights the theme; let it inherit `currentColor`.
- With a click handler on the mark itself; wrap it in a real link/button.

## Accessibility

- Default exposes `role="img"` with an accessible name from `title`
  (`"Digitaltableteur"`).
- Use `decorative` when the brand is already named by adjacent text — the mark is
  then `aria-hidden`.
- The pulse only runs on hover and is disabled under `prefers-reduced-motion`.

## Promotion notes

Promoted to **beta** after verification: light/dark rendering confirmed in
Storybook (mark inherits `currentColor`), the `ForcedColors` story passes axe
(`fill="currentColor"` → system `CanvasText`), reduced-motion suppresses the
pulse, and all Logo tests pass (7/7). Stable promotion pending broader
production-consumer evidence.
