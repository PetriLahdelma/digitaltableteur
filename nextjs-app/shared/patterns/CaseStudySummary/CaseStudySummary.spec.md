# CaseStudySummary

Leads a case study with the decision-maker's questions answered first: what changed, who did what, what made it hard, which decisions shaped it, and how each claim can be checked. The process narrative follows below it.

## Rules

- Every evidence item MUST carry a source label. Self-reported figures say so ("Self-reported, from project records").
- Figures MUST come from records; the pattern never presents an unsourced metric.
- Link an evidence item only when a public source exists.
