# Tokens

All design tokens are **CSS custom properties** on `:root` (light) with overrides under `.themeDark`, `.themeHCB`, and `.themeHCW`.

## Catalog

- **163 tokens** in the light `:root` block (see `foundations/token-catalog.json`, generated by `npm run build:tokens`).
- Storybook foundation stories render **live specimens** with computed values per theme.

## Categories

| Category | Prefix examples | Use for |
|----------|-----------------|---------|
| Color | `--color-*`, `--accent-*` | Text, surfaces, borders, status |
| Typography | `--font-size-*`, `--font-*` | Type scale & stacks |
| Space | `--space-layout-*`, `--space-internal-*` | Margins/gaps vs padding |
| Motion | `--duration-*`, `--ease-*` | Transitions & GSAP |
| Layout | `--breakpoint-*`, `--container-*` | Grid & page structure |
| Radius | `--radius-*` | Corners |
| Elevation | `--modal-*` | Shadows & overlays |
| Focus | `--focus-ring-*` | Keyboard focus |

## Spacing model

- **Layout** (`--space-layout-*`) — margins between sections, grid gaps, page gutters.
- **Internal** (`--space-internal-*`) — padding inside buttons, inputs, cards.

## Do / Don't

| Do | Don't |
|----|-------|
| `padding-inline: var(--space-internal-16)` | `padding: 16px` |
| `color: var(--color-text)` | `color: #041b23` |
| Extend `variables.css`, then run `build:tokens` | Import `_wip-scaffold/*.json` in app CSS |

## Tailwind v4 utilities

Production tokens are bridged into `app/tailwind.css` inside the auto-generated **DT-THEME** block (`npm run build:tokens`). Use the `dt` namespace to avoid clashing with shadcn theme keys:

| CSS variable | Tailwind examples |
|--------------|-------------------|
| `--color-success` | `bg-dt-success`, `text-dt-success` |
| `--color-error` | `bg-dt-error`, `border-dt-error` |
| `--font-size-title-m` | `text-dt-title-m` |
| `--radius-lg` | `rounded-dt-lg` |

Spacing and shadcn semantic colors remain on the existing `@theme` keys (`spacing-layout-16`, `bg-primary`, etc.).

TypeScript helpers: `foundations/dist/tailwind.tokens.ts` (`tokenNames`, `tailwindThemeRefs`).
