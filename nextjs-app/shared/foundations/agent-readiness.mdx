## CLI

```bash
npm run find-component -- "confirm before deleting"
```

Returns ranked matches with status, tier, the `@dt/*` import, a description and how many production files use each one, so the agent picks an existing component before writing a new one.

## MCP server

```bash
npm run ds:mcp
```

Starts `digitaltableteur-design-system` over stdio for Claude Desktop, Cursor and similar clients. Production serves the same tools over HTTP at `/mcp`.

## Evals

Retrieval and composition quality is measured, not assumed.

```bash
npm run agent:eval            # the full agent eval
npm run agent:eval:intents    # intent to component retrieval
npm run agent:eval:patterns   # pattern composition
```

Read the scores against held-out tasks. A grader tuned on the bugs it is scored on will always look better than it is.
