## House rules

1. Add a token to `variables.css` first, then run `npm run build:tokens`. Never import the generated JSON at runtime.
2. Style components with CSS Modules and `var(--token)`. No hard-coded colours, sizes or spacing.
3. Use logical properties such as `margin-inline` and `padding-block`, so layouts follow the writing direction.
4. Test in every theme and language before you call something done. The Storybook toolbar switches both.

## Stack

React 19 and TypeScript in strict mode, styled with CSS Modules over custom properties. Storybook 10 for documentation, Vitest with Testing Library and axe for tests, and i18next for translations. The site that consumes it all runs on Next.js 16.
