## Consumption

Four packages publish to npm and are consumed back into the site: `@digitaltableteur/react`, `@digitaltableteur/web-components`, `@digitaltableteur/tokens` and `@digitaltableteur/tokens-css`. Raising direct imports from the package is a standing goal, one component at a time. `npm run report:component-usage` regenerates the figures above.

## Not planned

- Importing `foundations/dist/tokens.css` at runtime (ADR-0004).
- Copying another system's palette or spacing values into this repo (ADR-0005).

## Commands

```bash
npm run build:tokens            # catalog, DTCG, dist, Tailwind bridge and agent manifest
npm run check:contrast          # WCAG AA semantic pairs in every theme
npm run check:radius-shadow     # radius and elevation token discipline
npm run validate:components     # all component gates
npm run audit:catalog           # catalog completeness against the codebase
npm run report:component-usage  # npm consumption figures
```
