## Two kinds of space

Layout space (`--space-layout-*`) separates blocks: sections, cards in a grid, a heading and the paragraph under it. Internal space (`--space-internal-*`) pads the inside of a block: a button label, a card body, an input. Keeping them apart lets the page breathe without making controls bloated, and the reverse.

## Adding a token

1. Check the [token catalog](?path=/story/foundations-token-catalog--overview) first. Most needs are already covered.
2. Add it to `variables.css` with a usage comment, and give every theme a value.
3. Run `npm run build:tokens` and commit the regenerated files.
4. Run `npm run check:contrast` if it is a colour that text sits on.

## Tailwind

The build writes a DT-THEME block into `app/tailwind.css` that maps tokens into the `dt` namespace, so they never collide with the shadcn keys.

## Checks

`check:tokens` flags raw colours that should be semantic tokens and `check:phantom-tokens` flags references to tokens that do not exist; both run in `npm run lint:all`. `check:token-descriptions` makes sure every token explains its use.
