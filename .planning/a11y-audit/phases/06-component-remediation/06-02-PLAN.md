<task type="auto">
  <name>Task 1: Add aria-invalid and aria-describedby to Input component</name>
  <files>nextjs-app/shared/components/Inputs/Inputs.tsx</files>
  <action>
Update the Input component to include proper ARIA error attributes.

**Current issues:**
1. Input uses label text as ID (brittle, not unique)
2. Missing `aria-invalid` attribute on error state
3. Missing `aria-describedby` to link error message

**Changes needed:**

1. Generate stable unique ID using `React.useId()`:
```tsx
const inputId = React.useId();
const errorId = `${inputId}-error`;
const helperId = `${inputId}-helper`;
```

2. Compute hasError flag:
```tsx
const hasError = !!(error || phoneError || emailError);
const errorMessage = error || phoneError || emailError;
```

3. Compute aria-describedby value:
```tsx
const describedBy = [
  hasError && errorId,
  helperText && !hasError && helperId,
].filter(Boolean).join(' ') || undefined;
```

4. Update the input element:
```tsx
<input
  id={inputId}  // Use generated ID instead of label
  name={label.replace(/\s+/g, "-").toLowerCase()}
  className={...}
  type={type}
  placeholder={placeholder}
  value={inputValue}
  onChange={handleChange}
  disabled={effectiveDisabled}
  aria-invalid={hasError}
  aria-describedby={describedBy}
  {...rest}
/>
```

5. Update Label to use inputId:
```tsx
<Label
  htmlFor={inputId}
  ...
>
```

6. Add IDs to HelperText elements:
```tsx
{hasError && (
  <HelperText id={errorId} state="error">
    {errorMessage}
  </HelperText>
)}
{helperText && !hasError && (
  <HelperText id={helperId}>{helperText}</HelperText>
)}
```

  <action>
Update HelperText to use `role="alert"` when displaying error state.

**Why:** Error messages should be announced immediately by screen readers. The `role="alert"` has implicit `aria-live="assertive"`.

**Changes:**

1. Add conditional role prop based on state:
```tsx
const HelperText = React.forwardRef<HTMLParagraphElement, HelperTextProps>(
  ({ children, id, className, state }, ref) => {
    // ... existing code ...

    return (
      <p
        ref={ref}
        id={id}
        className={mergedClassName}
        role={state === "error" ? "alert" : undefined}
      >
        {icon && <span className={styles.icon}>{icon}</span>}
        {children}
      </p>
    );
  },
);
```

**Note:** Only error state gets role="alert". Warning/info/success are not urgent enough to warrant assertive announcement.

describe("accessibility", () => {
  it("should have aria-invalid when there is an error", () => {
    render(<Input label="Email" type="email" error="Invalid email" />);
    const input = screen.getByRole("textbox");
    expect(input).toHaveAttribute("aria-invalid", "true");
  });

  it("should not have aria-invalid when there is no error", () => {
    render(<Input label="Email" type="email" />);
    const input = screen.getByRole("textbox");
    expect(input).not.toHaveAttribute("aria-invalid");
  });

  it("should have aria-describedby pointing to error message", () => {
    render(<Input label="Email" type="email" error="Invalid email" />);
    const input = screen.getByRole("textbox");
    const describedBy = input.getAttribute("aria-describedby");
    expect(describedBy).toBeTruthy();
    const errorElement = document.getElementById(describedBy!);
    expect(errorElement).toHaveTextContent("Invalid email");
  });

  it("should have aria-describedby pointing to helper text when no error", () => {
    render(<Input label="Email" type="email" helperText="We'll never share your email" />);
    const input = screen.getByRole("textbox");
    const describedBy = input.getAttribute("aria-describedby");
    expect(describedBy).toBeTruthy();
    const helperElement = document.getElementById(describedBy!);
    expect(helperElement).toHaveTextContent("We'll never share your email");
  });
});
