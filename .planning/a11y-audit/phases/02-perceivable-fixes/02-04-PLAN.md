  <action>
Create a Playwright test that verifies content reflow and zoom behavior.

The test should cover:

1. **Reflow at 320px (PERC-05)**
   - Set viewport to { width: 320, height: 568 } (iPhone SE equivalent)
   - Navigate to each public page
   - Check document.body.scrollWidth <= window.innerWidth
   - If scrollWidth > innerWidth, there's horizontal overflow
   - Capture screenshot for visual reference

2. **200% Zoom Simulation (PERC-04)**
   - Set viewport to { width: 640, height: 480 } (simulates 200% zoom on 1280px screen)
   - Or use CSS zoom via page.evaluate: document.body.style.zoom = '2'
   - Navigate to pages and check for overflow
   - Capture screenshot

3. **Text Spacing Test (1.4.12)**
   - Apply WCAG text spacing override:
     ```js
     document.body.style.lineHeight = '1.5';
     document.body.style.letterSpacing = '0.12em';
     document.body.style.wordSpacing = '0.16em';
     // Add paragraph margin
     ```
   - Check for overflow/clipping

Pattern:
```typescript
import { test, expect } from '@playwright/test';

const pages = [
  { name: 'Home', path: '/' },
  { name: 'About', path: '/about' },
  { name: 'Contact', path: '/contact' },
  { name: 'Work', path: '/work' },
  { name: 'Blog', path: '/blog' },
];

test.describe('Reflow and Zoom Tests', () => {
  test.describe('320px Reflow (PERC-05)', () => {
    for (const { name, path } of pages) {
      test(`${name} page reflows at 320px`, async ({ page }) => {
        await page.setViewportSize({ width: 320, height: 568 });
        await page.goto(path);
        await page.waitForLoadState('networkidle');

        const hasHorizontalScroll = await page.evaluate(() => {
          return document.body.scrollWidth > window.innerWidth;
        });

        // Capture for review, don't fail
        if (hasHorizontalScroll) {
          console.log(`[WARN] ${name}: Horizontal scroll detected at 320px`);
          await page.screenshot({ path: `test-results/reflow-${name}-320px.png` });
        }
      });
    }
  });

  test.describe('200% Zoom Simulation (PERC-04)', () => {
    // Similar pattern with 640px viewport
  });
});
```
