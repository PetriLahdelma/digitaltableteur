  <name>Task 1: Create theme-aware contrast test suite</name>
  <files>tests/a11y/perceivable/color-contrast-audit.spec.ts</files>
  <action>
Create a Playwright test that audits color contrast across all 4 themes.

The test should:
1. Import AxeBuilder from @axe-core/playwright
2. Define theme classes: ['themeLight', 'themeDark', 'themeHCB', 'themeHCW']
   - Note: Light theme is default (no class), others have class on body/html
3. Define key pages to test (home, about, contact, blog at minimum)
4. For each theme:
   a. Navigate to page
   b. If not light theme, add theme class to html element via page.evaluate:
      `document.documentElement.classList.add('themeDark')` etc.
   c. Wait for styles to apply (networkidle or small delay)
   d. Run axe with rules:
      - 'color-contrast' (text contrast 4.5:1)
      - 'link-in-text-block' (links distinguishable)
   e. Collect violations by theme
5. Generate summary report

Test captures data for review, does not fail on violations.

Important: The site uses CSS classes on html element for theming:
- Light: no class (default)
- Dark: class="themeDark"
- High Contrast Black: class="themeHCB"
- High Contrast White: class="themeHCW"
