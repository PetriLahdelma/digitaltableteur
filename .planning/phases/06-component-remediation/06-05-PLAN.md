Purpose: When panels are conditionally rendered (removed from DOM when closed), the aria-controls relationship is broken. Screen readers cannot find the referenced panel. Using `hidden` attribute keeps the panel in DOM but hides it.

Output: Accordion component with panels always in DOM, using hidden attribute for visibility
</objective>

<task type="auto">
  <name>Task 1: Replace conditional render with hidden attribute</name>
  <files>nextjs-app/shared/components/Accordion/Accordion.tsx</files>
  <action>
Update the Accordion component to always render panels, using `hidden` attribute for visibility.

**Current code (lines ~48-58):**
```tsx
{open && (
  <div
    id={`panel-${item.id}`}
    className={styles.content}
    role="region"
    aria-labelledby={`trigger-${item.id}`}
  >
    {item.content}
  </div>
)}
```

**Update to:**
```tsx
<div
  id={`panel-${item.id}`}
  className={styles.content}
  role="region"
  aria-labelledby={`trigger-${item.id}`}
  hidden={!open}
>
  {item.content}
</div>
```

**Key changes:**
1. Remove the `{open && ...}` conditional wrapper
2. Add `hidden={!open}` to the panel div
3. Panel is always in DOM, just hidden when not open

**Why this matters:**
- `aria-controls="panel-xyz"` must reference an element that exists
- When conditionally rendered, closed panels don't exist in DOM
- Screen readers report "aria-controls references non-existent element"
- Using `hidden` keeps the element present but not displayed

**CSS consideration:**
The `hidden` attribute sets `display: none` by default. If the component uses custom CSS for visibility, you may need to ensure styles don't conflict. Check if `styles.content` has display rules that override `hidden`.

If styles conflict, add this to the CSS module:
```css
.content[hidden] {
  display: none;
}
```

**Add these test cases:**

```tsx
describe("accessibility", () => {
  const items = [
    { id: "item1", title: "Section 1", content: "Content 1" },
    { id: "item2", title: "Section 2", content: "Content 2" },
  ];

  it("should always have panels in DOM for aria-controls validity", () => {
    render(<Accordion items={items} />);
    // Both panels should exist even when closed
    items.forEach(item => {
      const panel = document.getElementById(`panel-${item.id}`);
      expect(panel).toBeInTheDocument();
    });
  });

  it("should use hidden attribute on closed panels", () => {
    render(<Accordion items={items} />);
    const panel = document.getElementById("panel-item1");
    expect(panel).toHaveAttribute("hidden");
  });

  it("should not have hidden attribute on open panel", () => {
    render(<Accordion items={items} defaultOpenId="item1" />);
    const openPanel = document.getElementById("panel-item1");
    const closedPanel = document.getElementById("panel-item2");
    expect(openPanel).not.toHaveAttribute("hidden");
    expect(closedPanel).toHaveAttribute("hidden");
  });

  it("should have valid aria-controls reference when panel is hidden", () => {
    render(<Accordion items={items} />);
    const trigger = screen.getByRole("button", { name: "Section 1" });
    const controlsId = trigger.getAttribute("aria-controls");
    const panel = document.getElementById(controlsId!);
    expect(panel).toBeInTheDocument();
  });
});
```
