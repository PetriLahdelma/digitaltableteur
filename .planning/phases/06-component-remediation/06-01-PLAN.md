<task type="auto">
  <name>Task 1: Remove aria-live from Modal dialog element</name>
  <files>nextjs-app/shared/components/Modal/Modal.tsx</files>
  <action>
Remove the `aria-live` attribute from the modal container div (lines 143-148 and 177).

The current code incorrectly calculates aria-live based on severity:
```tsx
const ariaLive =
  severity === "error" || severity === "warning"
    ? "assertive"
    : severity === "info" || severity === "success"
      ? "polite"
      : undefined;
```

And applies it to the dialog:
```tsx
<div
  role={dialogRole}
  aria-modal="true"
  aria-live={ariaLive}  // REMOVE THIS
  ...
>
```

**Why this is wrong:**
- `role="alertdialog"` already implies `aria-live="assertive"`
- `role="dialog"` does not need aria-live (it's announced when opened)
- Adding aria-live causes double announcement

**Fix:**
1. Remove the `ariaLive` const calculation (lines 143-148)
2. Remove `aria-live={ariaLive}` from the dialog div props (line 177)

Keep everything else - the role selection logic is correct (alertdialog for error/warning, dialog for others).
  </action>
  <verify>Run `npm run typecheck` to ensure no TypeScript errors</verify>
  <done>Modal no longer has aria-live attribute on dialog element</done>
</task>
