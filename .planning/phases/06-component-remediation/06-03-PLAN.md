```tsx
return (
  <div
    className={styles.messages}

  >
```

**ARIA attributes explained:**
- `role="log"`: Semantic role indicating sequential content where new entries are added
- `aria-live="polite"`: Announces new messages after current speech finishes
- `aria-label`: Provides accessible name for the region
- `aria-relevant="additions"`: Only announce when new content is added (not removals)
