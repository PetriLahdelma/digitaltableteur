**Design differentiation strategy for Raw View (editorial/print project):**
Raw View is a PRINT PUBLICATION project - the styling should feel different from digital-focused case studies (VertaaUX, Finnish Transport Agency).

Editorial/magazine-inspired styling elements:
1. **Generous whitespace** - More breathing room, like a publication spread
2. **Pull-quote styling** - Editorial callout treatment for key statements
3. **Different section rhythm** - Asymmetric spacing, not uniform
4. **Subtle typographic refinements** - Letter-spacing on subtitles
5. **Image presentation** - Full-bleed feel, minimal borders (unlike FTA's structured borders)
6. **Process section** - Different background treatment from other case studies

Avoid: Structured grid feel (FTA), card-heavy layouts, tight spacing.
</context>

  <action>
    Expand the CSS module with unique editorial styling for Raw View page.

    Replace existing content with enhanced editorial-inspired styles:

    ```css
    /* Raw View - Editorial/Publication inspired styling */

    .page {
      background-color: var(--main-body-background-color);
    }

    /* Editorial-inspired generous spacing */
    .storySection {
      margin-block: var(--space-layout-80, 5rem);
    }

    /* Asymmetric rhythm - first story section closer to meta */
    .storySection:first-of-type {
      margin-block-start: var(--space-layout-48);
    }

    /* Process section - subtle editorial tone */
    .processSection {
      margin-block: var(--space-layout-80, 5rem);
      padding-block: var(--space-layout-48);
    }

    /* Image grid with editorial breathing room */
    .imageGrid {
      margin-block: var(--space-layout-80, 5rem);
    }

    /* Editorial image presentation - clean, no borders */
    .imageGrid img {
      border-radius: 0;
    }

    /* Pull-quote inspired subtitle treatment */
    .storySection [data-story-subtitle] {
      letter-spacing: 0.1em;
      text-transform: uppercase;
      font-size: var(--font-size-xs);
      color: var(--color-text-secondary);
    }

    /* Process phase titles - editorial weight */
    .processSection [data-process-title] {
      letter-spacing: 0.05em;
    }

    /* Outcomes section - editorial finale */
    .outcomesSection {
      margin-block: var(--space-layout-96, 6rem);
      padding-block: var(--space-layout-48);
      border-block-start: 1px solid var(--color-border-subtle, rgba(0, 0, 0, 0.1));
    }

    /* Magazine-style image captions */
    .storySection figcaption,
    .imageGrid figcaption {
      font-style: italic;
      color: var(--color-text-secondary);
      margin-block-start: var(--space-layout-12);
    }
    ```

    Note: The attribute selectors [data-story-subtitle] and [data-process-title] may or may not match depending on component internals. The class-based rules are the primary differentiation. If the attribute selectors don't apply, that's acceptable - the spacing and layout rhythm create sufficient differentiation.
