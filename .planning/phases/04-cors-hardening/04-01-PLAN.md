**Established pattern (from chat-shared.ts):**
- `allowedOrigins` array: production domains + localhost variants
- `resolveAllowedOrigin(origin)`: validates origin, returns allowed or default
- `createCorsHeaders(origin)`: returns headers with validated origin + `Vary: Origin`
- Already used successfully in `app/api/chat/route.ts`

**Key security insight:**
- Wildcard `*` allows any website to make requests to our API
- With validated origins, only trusted domains can interact
- `Vary: Origin` header ensures CDN/proxy caching respects origin
