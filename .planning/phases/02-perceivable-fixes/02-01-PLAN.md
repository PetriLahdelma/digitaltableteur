  <action>
Create a Playwright test that specifically audits image accessibility across all public pages.

The test should:
1. Import AxeBuilder from @axe-core/playwright
2. Define all public page URLs (same as existing audit)
3. For each page, run axe with tags: ['wcag2a', 'wcag21a'] and rules focused on images:
   - 'image-alt' (images must have alt)
   - 'image-redundant-alt' (no redundant alt text)
   - 'input-image-alt' (image buttons need alt)
   - 'role-img-alt' (role="img" elements need labels)
   - 'svg-img-alt' (SVG with role="img" need labels)
4. Collect results and output summary
5. Test should NOT fail - it captures data for manual review

Pattern to follow from existing tests/a11y/playwright.a11y.spec.ts

Use withRules() to focus on image-specific rules.
