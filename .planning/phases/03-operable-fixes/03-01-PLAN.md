<task type="auto">
  <name>Task 1: Fix Accordion trigger focus visibility</name>
  <files>nextjs-app/shared/components/Accordion/Accordion.module.css</files>
  <action>
Add `:focus-visible` styling to the `.trigger` class. Use the same pattern as Button.module.css (lines 22-51):

```css
.trigger:focus-visible {
  outline: var(--focus-ring-width, 2px) solid var(--focus-ring-color, var(--color-primary));
  outline-offset: var(--focus-ring-offset, 2px);
}

/* Windows High Contrast Mode support */
@media (forced-colors: active) {
  .trigger:focus-visible {
    outline: 3px solid Highlight;
    outline-offset: 2px;
    forced-color-adjust: none;
  }
}
```

Insert after line 24 (after the .trigger rule block, before .content).

This follows the established pattern in the codebase:
- Uses `:focus-visible` (not `:focus`) to avoid showing focus ring on mouse click
- Uses CSS custom properties for theme-aware colors
- Includes Windows High Contrast Mode support
