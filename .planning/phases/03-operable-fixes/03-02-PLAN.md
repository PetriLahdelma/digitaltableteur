Create Playwright tests covering OPER-01 (keyboard accessibility) and OPER-05 (focus order):

**Test sections:**

1. **OPER-01: Basic Tab Navigation**
   - Tab through all interactive elements on each public page
   - Verify no elements are skipped
   - Verify Tab reaches all buttons, links, and form inputs

2. **OPER-01: Button Activation**
   - Verify Enter key activates buttons
   - Verify Space key activates buttons
   - Test on primary, secondary, and tertiary variants

3. **OPER-01: Tabs Component Navigation**
   - Verify Tab moves focus into tab list
   - Verify Arrow Left/Right navigates between tabs
   - Verify Home goes to first tab, End goes to last tab
   - Verify Enter/Space activates tab

4. **OPER-01: Accordion Component Navigation**
   - Verify Tab focuses accordion triggers
   - Verify Enter/Space toggles accordion panels
   - Verify aria-expanded updates correctly

5. **OPER-05: Focus Order Verification**
   - Tab through home page, verify order matches visual layout
   - Check that modals/portals don't break focus order when closed

**Pages to test:** /, /about, /work, /blog, /contact

**Pattern:** Use `page.keyboard.press("Tab")` and `expect(locator).toBeFocused()`
