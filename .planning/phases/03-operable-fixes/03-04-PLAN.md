<task type="auto">
  <name>Task 1: Fix Button.sm touch target for mobile</name>
  <files>nextjs-app/shared/components/Button/Button.module.css</files>
  <action>
The `.button.sm.iconOnly` and `.button.s.iconOnly` classes are 24x24px (1.5rem) which fails the 44x44px mobile touch target requirement.

Add a responsive override for mobile viewports (max-width: 768px) that increases the touch target size without changing visual appearance:

**Option A (Recommended): Increase actual size on mobile**
```css
@media (max-width: 768px) {
  .button.sm.iconOnly,
  .button.s.iconOnly {
    block-size: 2.75rem; /* 44px */
    inline-size: 2.75rem; /* 44px */
    min-inline-size: 2.75rem;
  }
}
```

**Important considerations:**
- This goes at the end of the file, after line 405 (after existing mobile media query)
- Uses `block-size`/`inline-size` for logical properties consistency
- Increases both `.sm` and `.s` variants (they are aliases)
- The icon inside remains centered due to flexbox
- `.md.iconOnly` (2.5rem = 40px) is close to 44px - consider including if space permits

**Do NOT use invisible padding approach** - it can cause layout issues with adjacent elements.
  </action>
