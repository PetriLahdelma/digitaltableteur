<task type="auto">
  <name>Task 2: Fix timing attack in test-health/runs endpoint</name>
  <files>app/api/test-health/runs/route.ts</files>
  <action>
Replace the vulnerable direct string comparison on line 134 with constant-time comparison.

**Current vulnerable code (line 134):**
```typescript
if (!HEALTH_TOKEN || providedToken !== HEALTH_TOKEN) {
```

**Fix:**
1. Import `timingSafeEqual` from "crypto" at the top
2. Add `constantTimeCompare` helper function (same pattern as download-cv)
3. Replace line 134 with constant-time comparison

**Implementation:**
```typescript
import { timingSafeEqual, randomUUID } from "node:crypto";

// Add after HEALTH_TOKEN definition
function constantTimeCompare(a: string, b: string): boolean {
  if (a.length !== b.length) return false;
  const bufA = Buffer.from(a, "utf8");
  const bufB = Buffer.from(b, "utf8");
  return timingSafeEqual(bufA, bufB);
}

// Replace line 134 with:
if (!HEALTH_TOKEN || !providedToken || !constantTimeCompare(providedToken, HEALTH_TOKEN)) {
```

**Why this matters:**
- Direct `!==` comparison returns early on first mismatched character
- Attackers can measure response times to guess tokens character-by-character
- `timingSafeEqual` takes constant time regardless of where mismatch occurs
