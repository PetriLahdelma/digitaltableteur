    ## Technical Specifications

    This site uses the following technologies:
    - HTML5
    - CSS (with CSS custom properties)
    - JavaScript (React 19, Next.js 15)
    - WAI-ARIA (Accessible Rich Internet Applications)

    Accessibility features rely on:
    - Semantic HTML structure
    - Keyboard navigation support
    - Screen reader compatibility (VoiceOver, NVDA)
    - Four theme options including high contrast modes
    - Responsive design from 320px viewport width

    ## Testing Methodology

    We tested this site using:
    - **Automated:** axe-core accessibility testing library (188 page combinations)
    - **Screen readers:** VoiceOver (macOS/Safari), NVDA (Windows/Firefox)
    - **Keyboard:** Full keyboard navigation verification
    - **Visual:** Color contrast, zoom to 200%, high contrast modes

    ## Accessibility Features

    This site includes the following accessibility features:
    - **Skip to content link** - bypass navigation and jump to main content
    - **Theme options** - Light, Dark, High Contrast Black, High Contrast White
    - **Keyboard navigation** - all functionality available via keyboard
    - **Form labels** - all form inputs have visible labels
    - **Error messages** - form errors identified and described
    - **Focus indicators** - visible focus outline on all interactive elements
    - **Alt text** - meaningful descriptions for images
    - **Responsive design** - works from 320px to any screen size

    ## Assessment Information

    - **Audit date:** [date]
    - **Audited by:** Internal team with automated and manual testing
