<task type="checkpoint:human-verify" gate="blocking">
  <name>Task 1: VoiceOver + Keyboard Testing - Core Pages</name>
  <what-built>
    Claude will guide you step-by-step through VoiceOver and keyboard testing on each of the 5 core pages.
    This is interactive testing - Claude provides instructions, you execute and report findings.
  </what-built>
  <how-to-verify>
    **Prerequisites:**
    1. Open Safari and navigate to http://localhost:3000
    2. Enable VoiceOver: Cmd+F5
    3. Have the VoiceOver quick reference ready (Ctrl+Option = VO key)

    **Testing Process per Page:**
    Claude will guide you through testing each page with this structure:

    1. **Page Structure** (VO+U to open rotor)
       - Verify landmarks exist (main, nav, banner)
       - Verify heading hierarchy (single h1, logical levels)
       - Verify page title announcement

    2. **Content Navigation** (VO+Right/Left Arrow)
       - Verify all content is announced
       - Verify images have alt text or are marked decorative
       - Verify links describe destinations

    3. **Interactive Elements**
       - Verify buttons announce name + role
       - Verify form fields announce label + type + required status
       - Verify expandable content announces state

    4. **Keyboard Navigation** (Tab, Shift+Tab, Enter, Space, Escape)
       - Verify all elements focusable
       - Verify focus order is logical
       - Verify skip link works
       - Verify no keyboard traps

    5. **Dynamic Content**
       - Verify toast messages announced via live region
       - Verify form errors announced
       - Verify chat widget messages announced

    **Pages to Test:**
    - Home (/)
    - About (/about)
    - Work (/work)
    - Blog (/blog)
    - Contact (/contact)

    **Fix-Then-Continue Workflow:**
    If ANY issue is found:
    1. Stop testing
    2. Report the issue to Claude
    3. Claude will provide a fix
    4. Apply the fix
    5. Retest the specific element
    6. Continue from where you stopped
  </how-to-verify>
  <resume-signal>Report "Core pages testing complete" with results summary, or report any issues found during testing</resume-signal>
</task>
