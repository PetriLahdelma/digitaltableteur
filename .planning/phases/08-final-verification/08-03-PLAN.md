<task type="checkpoint:human-verify" gate="blocking">
  <name>Task 2: Windows Forced Colors Emulation</name>
  <what-built>
    Claude will guide you through testing Windows Forced Colors mode using browser emulation.
    This validates CSS forced-colors media query support.
  </what-built>
  <how-to-verify>
    **Setup:**
    1. Open Chrome DevTools (Cmd+Option+I)
    2. Press Cmd+Shift+P (Mac) or Ctrl+Shift+P
    3. Type "rendering" and select "Show Rendering"
    4. Scroll to "Emulate CSS media feature forced-colors"
    5. Select "forced-colors: active"

    **Pages to Test:**
    - Home (/)
    - Contact (/contact)
    - One blog post

    **Forced Colors Tests:**

    1. **Focus Visibility**
       - Tab through page
       - Verify focus ring uses system Highlight color
       - Verify 3px outline visible

    2. **Button Outlines**
       - Verify buttons have visible borders
       - Verify button text readable

    3. **Link Visibility**
       - Verify links use system LinkText color
       - Verify links distinguishable from body text

    4. **Form Controls**
       - Verify input borders visible
       - Verify placeholder text readable
       - Verify error states visible

    5. **Images and Icons**
       - Verify decorative images don't interfere
       - Verify icons with `currentColor` adapt

    **Note:** Forced colors completely overrides site colors.
    Site should remain USABLE, even if not visually identical.

    **Fix-Then-Continue:** Stop and fix any issues before continuing.
  </how-to-verify>
  <resume-signal>Report "Forced colors verification complete" or describe issues found</resume-signal>

<task type="checkpoint:human-verify" gate="blocking">
  <name>Task 4: Text Spacing Override Test</name>
  <what-built>
    Claude will guide you through testing WCAG 1.4.12 Text Spacing.
    This ensures content remains visible with increased text spacing.
  </what-built>
  <how-to-verify>
    **Setup:**
    1. Open Chrome DevTools (Cmd+Option+I)
    2. Go to Elements panel
    3. Click on `<html>` element
    4. In Styles, add a new style rule:

    ```css
    * {
      line-height: 1.5 !important;
      letter-spacing: 0.12em !important;
      word-spacing: 0.16em !important;
    }
    p {
      margin-bottom: 2em !important;
    }
    ```

    **Pages to Test:**
    - Home (/)
    - Contact (/contact)
    - Blog post (text-heavy)

    **Text Spacing Tests:**

    1. **No Content Cut Off**
       - All text still visible
       - No text clipped by containers

    2. **No Overlapping**
       - Text doesn't overlap other elements
       - Buttons text doesn't overflow

    3. **Readability**
       - Content still readable
       - Navigation still usable
       - Forms still functional

    **Note:** Layout may look different but must remain USABLE.

    **Fix-Then-Continue:** Stop and fix any issues before continuing.
  </how-to-verify>
  <resume-signal>Report "Text spacing verification complete" or describe issues found</resume-signal>
</task>
