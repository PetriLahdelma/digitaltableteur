# Contact Page Redesign

> Design specification for the Digitaltableteur contact page redesign.
> Created: 2026-01-15

## Design Philosophy

**Aesthetic Direction:** Editorial & refined, inspired by Primary Studio and It's Nice That — magazine-like composition with confident typography and intentional whitespace.

**Core Principles:**
- Typography does the heavy lifting
- Generous whitespace creates editorial breathing room
- Progressive disclosure respects user intent
- Morphing animations feel intelligent, not decorative
- Success state is confident and minimal

## Progressive Disclosure Form

### Tier 1: Core Fields (Always Visible)

| Field | Type | Required | Notes |
|-------|------|----------|-------|
| Name | text | Yes | — |
| Email | email | Yes | — |
| Message | textarea | Yes | Placeholder: "Tell us about your project..." |

### Expansion Trigger → Tier 2

```
[+ Add project details]
```

### Tier 2: Project Details

| Field | Type | Options |
|-------|------|---------|
| Budget range | select | Under €5k · €5–15k · €15–50k · €50k+ · Not sure yet |
| Timeline | select | ASAP · 1–2 months · 3–6 months · Flexible |
| Project type | select | Brand & Identity · Digital Product · Website · Creative Direction · Other |

### Expansion Trigger → Tier 3

```
[+ Tell us more]
```

### Tier 3: Relationship & Brief

| Field | Type | Notes |
|-------|------|-------|
| How did you find us? | select | Social media · Search · Word of mouth · Event · Existing client · Other |
| Attachments | file upload | Max 2MB, PDF/PNG/JPG |
| Inspiration / References | textarea | Optional, 2 rows |

## Animation Specifications

### Morphing Form Expansion

```css
/* Container height */
transition: height 500ms var(--ease-out-expo);

/* New fields: staggered FadeIn */
animation-delay: 60ms; /* between each field */
transform: translateY(16px) → translateY(0);
opacity: 0 → 1;
duration: 400ms;
```

### Success State Transition

1. Form fields fade out (200ms)
2. Container height reduces (400ms, `var(--ease-out-expo)`)
3. Success content fades in (300ms delay, then 400ms)

## Success State

### Content

```
┌─────────────────────────────────┐
│                                 │
│   Message sent.                 │  ← Syne, 32px
│                                 │
│   We'll be in touch shortly.    │  ← Satoshi, 16px, muted
│                                 │
│   [Send another message]        │  ← text link
│                                 │
└─────────────────────────────────┘
```

### Design Decisions

- No checkmark icon (too generic)
- No confetti (doesn't match editorial tone)
- No green success colors (stays in brand palette)
- Typography carries the message

### Component Responsibilities

| Component | Purpose |
|-----------|---------|
| `ContactFormEditorial` | Main form with 3-tier progressive disclosure, validation, submission |
| `FormFieldEditorial` | Styled input wrapper (bold label + underline/bordered input) |
| `ExpandableSection` | Reusable morphing container with height animation |
| `ContactFormSuccess` | Minimal success message (update existing) |
| `ContactPageContent` | Magazine spread layout composition (update existing) |

### Preserved Logic

All validation and submission logic from `EnhancedContactForm` should be preserved:
- Email regex validation
- Required field validation
- Honeypot spam protection
- File upload handling (2MB limit, type restrictions)
- API submission to `/api/contact`

## Future Considerations

### Automated Email (Post-project)

Set up Resend for transactional emails:
- Instant confirmation to sender
- Internal notification to Petri
- Follow-up sequence if no reply within 48h

### Accessibility Requirements

- All inputs have associated labels (via `FormFieldEditorial`)
- Error messages linked via `aria-describedby`
- Focus states visible (color + border change)
- Keyboard navigation preserved
- Screen reader announcements for form state changes
