# Git and PR reference

- **Area doc:** [`AGENTS.md`](../../../AGENTS.md) (universal conventions)
- **Branch naming:** `docs/BRANCH_NAMING.md` — prefix `DT-XXX-`
- **PR validation CI:** `.github/workflows/pr-validation.yml`

Use `gh` for all GitHub operations (issues, PRs, checks).
