# Akaunting Directory - AI Agent Quick Reference

## ⚠️ Critical: Authentication Method

**Self-hosted Akaunting uses Basic Authentication (username + password), NOT API keys.**

The API Key app is only available in Akaunting Cloud (paid subscription). For self-hosted installations:

- ✅ Use admin email and password for API access
- ✅ All requests require `X-Company: 1` header
- ✅ Authentication: `Authorization: Basic base64(username:password)`

## Purpose

Self-hosted accounting software (Akaunting) with Docker setup + VS Code MCP integration for automated bookkeeping, invoice generation, and financial management.

## Environment Variables (.env)

**Required**:

- `AKAUNTING_APP_KEY` - Laravel app key (auto-generated by setup.sh)
- `AKAUNTING_API_USERNAME` - Admin email (e.g., admin@digitaltableteur.com)
- `AKAUNTING_API_PASSWORD` - Admin password for API authentication
- `AKAUNTING_API_BASE_URL` - Default: `http://localhost:8080/api`
- `AKAUNTING_COMPANY_ID` - Default: `1`

**Optional**:

- `AKAUNTING_APP_URL` - For production: `https://accounting.digitaltableteur.eu`
- `AKAUNTING_DB_PASSWORD` - Default: `akaunting`
- `AKAUNTING_DB_ROOT_PASSWORD` - Default: `root`

**Important**: Self-hosted Akaunting uses **Basic Authentication** with username/password, not API keys. The API Key app is only available in Akaunting Cloud (paid).

## API Endpoints

Base: `http://localhost:8080/api`

**Authentication**: Basic Auth with `admin@digitaltableteur.com:password`  
**Required Header**: `X-Company: 1`

- `GET /invoices` - List invoices
- `POST /invoices` - Create invoice
- `GET /contacts` - List customers/vendors
- `POST /contacts` - Add customer/vendor
- `GET /transactions` - List transactions
- `POST /transactions` - Add expense/income
- `GET /items` - List products/services
- `GET /categories` - List categories
- `GET /reports/profit-loss` - Generate P&L report

Full API docs: https://akaunting.com/docs/api

## MCP Integration

After running `npm run akaunting:mcp:setup`, your `mcp.json` will contain:

```json
{
  "mcpServers": {
    "akaunting": {
      "type": "http",
      "baseUrl": "http://localhost:8080/api",
      "auth": {
        "type": "basic",
        "username": "{{AKAUNTING_API_USERNAME}}",
        "password": "{{AKAUNTING_API_PASSWORD}}"
      },
      "headers": {
        "X-Company": "1"
      }
    }
  }
}
```

## Common Tasks

### Enable API Access (First Time)

1. Open http://localhost:8080
2. Complete setup wizard with admin credentials
3. Use admin email/password for API authentication
4. Add credentials to `akaunting/.env`:
   ```
   AKAUNTING_API_USERNAME=admin@digitaltableteur.com
   AKAUNTING_API_PASSWORD=your_password
   ```

**Note**: Self-hosted Akaunting doesn't require API token generation. The API Key app is only available in Akaunting Cloud (paid subscription).

### Create Invoice via API

```bash
curl -X POST "http://localhost:8080/api/invoices" \
  -u "admin@digitaltableteur.com:YOUR_PASSWORD" \
  -H "X-Company: 1" \
  -H "Content-Type: application/json" \
  -d '{
    "invoiced_at": "2025-12-01",
    "due_at": "2025-12-15",
    "contact_id": 1,
    "currency_code": "EUR",
    "items": [{
      "name": "Website Design",
      "quantity": 1,
      "price": 1500.00,
      "tax_id": 1
    }]
  }'
```

### Backup Database

```bash
docker exec akaunting-db mysqldump -u akaunting -pakaunting akaunting > backup-$(date +%Y%m%d).sql
```

### Restore Database

```bash
docker exec -i akaunting-db mysql -u akaunting -pakaunting akaunting < backup-20251201.sql
```

## Troubleshooting

### Port 8080 in use

Edit `docker-compose.yml` ports: `"8081:80"` and update `.env` base URL

### 401 Unauthorized

1. Verify API key in `.env`
2. Check token hasn't expired in Akaunting dashboard
3. Ensure required modules are enabled

### Database connection failed

```bash
docker compose ps              # Check status
docker compose logs db         # View database logs
docker compose restart db      # Restart database
```

### Clear cache

```bash
docker exec -it akaunting-app php artisan cache:clear
docker exec -it akaunting-app php artisan config:clear
```

## Finnish Tax & Compliance Functions

Added specialized utilities for Finnish business compliance (available in `lib/akaunting-tools.mjs`):

### `generateVATSummary({ startDate, endDate, period })`

Generates ALV-ilmoitus (VAT return) matching Vero.fi form structure.

- **Returns**: Boxes 301-311 for OmaVero submission
- **Supports**: Monthly/quarterly periods
- **VAT rates**: 25.5%, 14%, 10%, 0% (2025 Finland)
- **Output format**: Ready for OmaVero electronic filing

```javascript
import { generateVATSummary } from "./lib/akaunting-tools.mjs";
const vat = await generateVATSummary({
  startDate: "2025-11-01",
  endDate: "2025-11-30",
  period: "monthly",
});
console.log(vat.omaVeroFormat); // Direct submission format
```

### `listMissingReceipts({ startDate, endDate, threshold })`

Identifies expenses without proper documentation (receipts/references).

- **Threshold**: Default €10 (Finnish requirement)
- **Risk assessment**: High/Medium/Low compliance risk
- **Compliance**: Meets Finnish Tax Administration requirements

```javascript
import { listMissingReceipts } from "./lib/akaunting-tools.mjs";
const missing = await listMissingReceipts({
  startDate: "2025-11-01",
  endDate: "2025-11-30",
});
// Shows transactions needing receipts before tax audit
```

### `prepareMonthlyReport({ year, month })`

Complete "Kuukauden kirjanpitoaineisto" package for accountant.

- **Includes**: Income statement, VAT summary, transaction lists
- **Checklist**: Invoices recorded, receipts attached, bank reconciled
- **Deliverables**: PDFs list for accountant delivery

```javascript
import { prepareMonthlyReport } from "./lib/akaunting-tools.mjs";
const report = await prepareMonthlyReport({ year: 2025, month: 11 });
console.log(report.deliverables); // Files to send accountant
```

### `yearEndPackage({ year })`

Annual "Tilinpäätösaineisto" for Finnish Tax Administration.

- **Financial statements**: Tuloslaskelma (income statement)
- **YEL calculation**: Entrepreneur pension insurance (15.5% rate)
- **Prepayment tax**: Progressive tax estimate
- **Archive requirements**: 6-year retention per Finnish law
- **Deadlines**: Tax return, VAT annual, YEL declaration

```javascript
import { yearEndPackage } from "./lib/akaunting-tools.mjs";
const yearEnd = await yearEndPackage({ year: 2025 });
console.log(yearEnd.yel.monthlyPremium); // YEL monthly payment
console.log(yearEnd.prepaymentTax.estimatedTax); // Tax liability
console.log(yearEnd.deadlines); // All filing deadlines
```

**Finnish Compliance Features**:

- ✅ VAT rates updated for 2025 (25.5% standard)
- ✅ YEL calculation with 2025 income limits (€8,839.41 - €209,945)
- ✅ Progressive tax brackets (2025 state income tax)
- ✅ OmaVero submission format
- ✅ 6-year archive requirement tracking
- ✅ Bilingual output (Finnish terms + English)
