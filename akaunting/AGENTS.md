# Akaunting Directory - AI Agent Quick Reference

## Purpose

Self-hosted accounting software (Akaunting) with Docker setup + VS Code MCP integration for automated bookkeeping, invoice generation, and financial management.

## Directory Structure

```
akaunting/
├── docker-compose.yml       # Docker setup for Akaunting + MariaDB
├── env.example              # Environment template
├── .env                     # Local config (gitignored)
├── setup.sh                 # Automated installation script
├── README.md                # Comprehensive documentation
├── QUICKSTART.md            # 5-minute setup guide
└── .gitignore              # Excludes sensitive files
```

## Quick Commands

```bash
# Installation (first time)
npm run akaunting:install

# Daily usage
npm run akaunting:start     # Start containers
npm run akaunting:stop      # Stop containers
npm run akaunting:restart   # Restart containers
npm run akaunting:logs      # View logs

# MCP integration
npm run akaunting:mcp:setup # Configure MCP
npm run akaunting:mcp:test  # Test API connection
```

## Environment Variables (.env)

**Required**:

- `AKAUNTING_APP_KEY` - Laravel app key (auto-generated by setup.sh)
- `AKAUNTING_API_KEY` - API token from Akaunting dashboard
- `AKAUNTING_API_BASE_URL` - Default: `http://localhost:8080/api/v1`

**Optional**:

- `AKAUNTING_APP_URL` - For production: `https://accounting.digitaltableteur.eu`
- `AKAUNTING_DB_PASSWORD` - Default: `akaunting`
- `AKAUNTING_DB_ROOT_PASSWORD` - Default: `root`

## Architecture

```
VS Code MCP Tools
       ↓ HTTP REST API (Bearer token)
Akaunting API (localhost:8080/api/v1)
       ↓
Docker Containers
  ├── akaunting-app (Akaunting PHP)
  └── akaunting-db (MariaDB)
```

## API Endpoints

Base: `http://localhost:8080/api/v1`

- `GET /invoices` - List invoices
- `POST /invoices` - Create invoice
- `GET /contacts` - List customers/vendors
- `POST /contacts` - Add customer/vendor
- `GET /transactions` - List transactions
- `POST /transactions` - Add expense/income
- `GET /items` - List products/services
- `GET /categories` - List categories
- `GET /reports/profit-loss` - Generate P&L report

Full API docs: https://akaunting.com/docs/api

## MCP Integration

After running `npm run akaunting:mcp:setup`, your `mcp.json` will contain:

```json
{
  "mcpServers": {
    "akaunting": {
      "type": "http",
      "baseUrl": "http://localhost:8080/api/v1",
      "auth": {
        "type": "bearer",
        "token": "your_api_key"
      }
    }
  }
}
```

## Security

- ✅ `.env` files are gitignored
- ✅ API uses Bearer token authentication
- ✅ Database not exposed externally (Docker network)
- ✅ HTTPS recommended for production
- ⚠️ Rotate API keys every 90 days
- ⚠️ Use read-only keys for reporting tasks

## Common Tasks

### Enable API Access (First Time)

1. Open http://localhost:8080
2. Complete setup wizard
3. Go to **Settings → Developer → API**
4. Click **Create Token**, name it "VS Code MCP"
5. Enable modules: invoices, contacts, items, transactions, reports, categories, expenses
6. Copy token to `akaunting/.env` as `AKAUNTING_API_KEY`

### Create Invoice via API

```bash
curl -X POST "http://localhost:8080/api/v1/invoices" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "invoiced_at": "2025-12-01",
    "due_at": "2025-12-15",
    "contact_id": 1,
    "currency_code": "EUR",
    "items": [{
      "name": "Website Design",
      "quantity": 1,
      "price": 1500.00,
      "tax_id": 1
    }]
  }'
```

### Backup Database

```bash
docker exec akaunting-db mysqldump -u akaunting -pakaunting akaunting > backup-$(date +%Y%m%d).sql
```

### Restore Database

```bash
docker exec -i akaunting-db mysql -u akaunting -pakaunting akaunting < backup-20251201.sql
```

## Troubleshooting

### Port 8080 in use

Edit `docker-compose.yml` ports: `"8081:80"` and update `.env` base URL

### 401 Unauthorized

1. Verify API key in `.env`
2. Check token hasn't expired in Akaunting dashboard
3. Ensure required modules are enabled

### Database connection failed

```bash
docker compose ps              # Check status
docker compose logs db         # View database logs
docker compose restart db      # Restart database
```

### Clear cache

```bash
docker exec -it akaunting-app php artisan cache:clear
docker exec -it akaunting-app php artisan config:clear
```

## Production Deployment

For EU-hosted deployment:

1. Deploy to Hetzner/UpCloud/Scaleway VPS
2. Set up reverse proxy with SSL (Caddy/Nginx)
3. Update `AKAUNTING_APP_URL` in `.env`
4. Configure firewall to restrict API access by IP
5. Set up automated daily backups via cron

See `docs/AKAUNTING_MCP_SETUP.md` for full production guide.
